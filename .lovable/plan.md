# クロール修正と「探す」画面の実装

## 変更内容

### 1. 公開トップページのリダイレクトを完全に除去
- `/` を開いた直後にログイン状態を調べて `/home` へ自動転送する処理を削除します。
- 「はじめる」を押した時だけログイン状態を確認し、ログイン済みならホーム、未ログインならログイン画面へ進めます。
- これにより、スマートフォン用 Googlebot が JavaScript 実行後も公開トップページから転送されません。
- ページ言語を日本語として明示します。

### 2. サイトマップを公開ページだけに整理
- サイトマップはインデックス対象の公開トップページだけを掲載します。
- ログイン画面は検索対象外として明示し、認証後ページや管理画面は引き続きサイトマップへ含めません。
- `robots.txt` のサイトマップ指定、トップページの canonical、既存の所有権確認タグは維持します。

### 3. 「フレンド」を「探す」に変更
- 下部メニューとホームタイルの「フレンド」を「探す」に変更します。
- 既存の届いたフレンド申請欄は残します。
- 募集投稿一覧の代わりに、登録済みアカウントを自分以外すべて表示します。

### 4. 登録者一覧を10件ずつ表示
- 名前、ユーザーID、アイコンを登録順で10件ずつ読み込みます。
- 前・次ボタンと現在ページ／総ページ数を表示します。
- 一覧の枠を押すと、既存のプロフィール詳細モーダルを開きます。
- 各行に「申請する」ボタンを置き、申請済み・フレンド済み・相手から申請中の状態では適切な表示に切り替えます。
- 既存の申請通知、承認・拒否、個別チャット機能は変更しません。

## 確認
- ビルドと実行時エラーを確認します。
- 未ログイン状態とスマートフォン用 Googlebot で `/`、`/robots.txt`、`/sitemap.xml` が転送ループなしで取得できることを確認します。
- ログイン済みの実画面で「探す」のページ切り替え、プロフィール表示、申請ボタンを確認します。

## 現時点の診断
- 公開中の `/`、`/robots.txt`、`/sitemap.xml` は現在すべて 200 で取得でき、サイトマップ自体も有効な XML です。
- Search Consoleの表示は前回クロール時点の記録である可能性がありますが、再発要因になり得るトップページの自動転送をコードから完全に外します。
- このプロジェクトにはSearch Console接続がないため、Google側の再審査操作は今回のコード変更には含めません。
